# PythonBanking
A CLI python project that lets you track and manage expenses, income, budget, and more.

In The Main Menu, You Can Log Expenses and Incomes And They Are Saved Across Sessions

You Can Set Budget Categories And Any Expenditures In A Budget Will Add To That budgets maximum

You can set goals for income, and any income in a goal will count in a status bar

Budgets automatically reset every month, but that can be disabled

Recurring expenses and incomes repeat themselves every month, starting on the day you logged them. They automatically save themselves every month when you activate this.

Requires Python, Not sure what version is needed, but I used python3.14.4

Functions on Linux, Probably on WSL, Do not think it will work on MacOS or Windows without some kind of port
